Tab groups extension

Back to board {{template "themebutton"}}

Opens each ticket's Jira issue, PR, plan and terminal in a browser tab group named after the ticket. Works in Chrome, Edge and Firefox 140 or later.

Install in Chrome or Edge

  1. Choose where to keep the extension. Taskboard writes a taskboard-tab-groups folder there, on this computer.

  2. Open chrome://extensions in a new tab and turn on Developer mode. Pages can't link there, so paste the address into the address bar.

  3. Choose Load unpacked, select the taskboard-tab-groups folder, then reload this page.

When taskboard is upgraded, the board rewrites the folder and the extension reloads itself. If the browser asks to let this site edit the folder, choose Allow on every visit so updates need no click.

Chrome or Edge

Download {{.ZipName}}

  1. Unzip {{.ZipName}} into a folder you'll keep. The browser loads it from there.
  2. Open chrome://extensions and turn on Developer mode.
  3. Choose Load unpacked and select the unzipped folder.

A zip doesn't update itself: download it again after upgrading taskboard and reload the extension.

Firefox

  1. Open about:debugging#/runtime/this-firefox.
  2. Choose Load Temporary Add-on and pick {{.ZipName}} from above.

Firefox removes temporary add-ons when it restarts. To keep it installed, sign it as an unlisted add-on with your own addons.mozilla.org API key: npx web-ext sign -s <unzipped folder> --channel=unlisted --api-key=... --api-secret=..., then install the .xpi it produces.
